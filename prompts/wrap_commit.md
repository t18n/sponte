# Wrap for merge

Ensure the working tree reflects all intended changes. Prepare **one** logical conventional commit ready to merge to `main`.

## Commit message rules (required)

- **Subject:** first line **50 characters or fewer** (Conventional Commits: `feat(scope):` / `fix(scope):` etc. if it fits).
- **Body:** omit if the subject is enough; otherwise leave a **blank line** after the subject, then **short bullet points** for only the most important changes; if you use prose instead, wrap at **72 characters** per line.
- **No AI attributions:** do not add trailers or footers such as `Made-with: Cursor` or similar.

If there are multiple commits, squash into one final commit following the above.

Do not push.
